Logo code — 3 easy ways (favicon + header/logo in page)

Below are ready-to-copy snippets and short instructions. Put your logo files in your project (e.g. /assets/logo.png, /favicon.ico) and update the href/src paths.

1) Favicon (the small icon in browser tab)

Place these inside <head> of your HTML (use the files you have — .ico, .png, or .svg):

html
<!-- basic .ico favicon (works well cross-browser) -->
<link rel="icon" href="/favicon.ico" />

<!-- PNG fallback (good for modern browsers) -->
<link rel="icon" type="image/png" sizes="32x32" href="/assets/favicon-32x32.png" />
<link rel="icon" type="image/png" sizes="16x16" href="/assets/favicon-16x16.png" />

<!-- Apple touch icon for iOS home screen -->
<link rel="apple-touch-icon" sizes="180x180" href="/assets/apple-touch-icon.png" />

<!-- optional: site manifest (for PWA / pinned tabs) -->
<link rel="manifest" href="/site.webmanifest" />

Notes:
• Recommended favicon sizes: 16×16, 32×32, 48×48 for PNG; 180×180 for Apple touch.
• If you change favicons, hard-refresh or clear cache (Chrome caches favicons aggressively).

2) Page header / navbar logo (inline image)

Put this where your header/nav is. Adjust CSS height/width to taste.

html
<!-- HTML (in your header/navigation) -->
<header class="site-header">
  <a href="/" class="brand">
    <img src="/assets/logo.png" alt="Your Site Name" class="brand-logo" />
  </a>
  <!-- rest of nav -->
</header>

css
/* CSS */
.site-header { display:flex; align-items:center; padding: 12px 16px; }
.brand { display:inline-flex; align-items:center; text-decoration:none; }
.brand-logo {
  height: 40px;        /* change to fit your header */
  width: auto;         /* keeps aspect ratio */
  display:block;
}
@media (max-width:600px) {
  .brand-logo { height: 32px; } /* responsive */
}

Accessibility: always include an appropriate alt attribute (e.g. site name).

3) SVG inline logo (crisp & easily styled)

If you have an SVG, embedding inline allows CSS color changes and scaling.

html
<!-- Inline SVG (paste your SVG content inside <svg>...</svg>) -->
<a href="/" class="brand">
  <svg class="brand-svg" viewBox="0 0 100 30" width="200" height="60" aria-label="Your Site Name" role="img">
    <!-- example shape -->
    <rect width="100" height="30" rx="4"></rect>
    <text x="10" y="20" font-family="sans-serif" font-size="12" fill="white">MySite</text>
  </svg>
</a>

css
.brand-svg { height: 40px; width: auto; }
.brand-svg svg, .brand-svg { display:block; }

4) Responsive images (srcset) — serves different resolutions

Good for high-DPI (retina) displays:

html
<img
  src="/assets/logo-1x.png"
  srcset="/assets/logo-1x.png 1x, /assets/logo-2x.png 2x"
  alt="Your Site Name"
  style="height:40px; width:auto;"
/>

Quick checklist for success

  • Put the files in the correct folder and update href/src.

  • Use an .ico for broad favicon support, and PNG/SVG for sharpness.

  • Include alt for accessibility.

  • Clear browser cache / do a hard reload if the old icon persists (Chrome: Ctrl+F5 or clear site data).

  • For production, prefer optimized images (small file sizes).
